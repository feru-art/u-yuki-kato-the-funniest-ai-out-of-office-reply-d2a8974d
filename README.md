## Variants

Five original one-line replies were built and raced head-to-head against
the judge criteria (in order: on-subject auto-reply, real laugh with a
surprise, machine voice, reads like a real auto-reply, fresh). See
`VARIANTS.md` for the full local race table. V4 won 4–0; V3 was second
(3–1); V2 was replaced after going 0–4 (it discarded the sender's message
and failed the on-subject / real-auto-reply criteria).
